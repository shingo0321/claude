# 模擬試験

> **注記**: この模擬試験は[練習問題](../practice-questions/)と同じ問題セットを使った自己採点ツールです。公式の試験ガイドの出題形式(問題数・配点比率・制限時間)に合わせて出題します。問題は選択式(4択)と複数選択(5択から2つを選ぶ形式を含む)で、Architect – Foundationsでは公式の6シナリオから4つを選び、1シナリオあたり15問(合計60問)を出題します。分野別の出題数は公式の配点比率に近づくよう調整します。出題順・選択肢の順序は開始のたびにランダムに入れ替わります。問題ごとに、解答を確定した時点で正答と解説が表示されます。確定後は選び直せません。以下の練習問題と同一のオリジナル問題であり、Anthropic公式の実際の試験問題ではありません。

> **本番の傾向(受験体験記より)**: 状況文が長く、選択肢のほとんどが一般論としては妥当に見える。決め手はシナリオ中の制約(コスト・レイテンシ・不可逆性・並行処理など)と、問いの末尾(**root cause** / **first step** / **lowest cost** / **minimal change**)。120分で60問なので1問2分弱。迷ったら印を付けて先へ進み、明らかに外れる選択肢を先に除外してから、残りを制約で比べる。
