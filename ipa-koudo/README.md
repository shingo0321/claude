# 情報処理技術者試験 高度試験区分 学習サイト

IPA(情報処理推進機構)の情報処理技術者試験のうち、**高度試験区分のみ**を対象にした学習ノート・過去問演習。現在は区分「プロジェクトマネージャ(PM)」のみ収録している。

> 過去問の問題文はIPAの著作物のため収録していない。各年度の公式PDF(問題冊子・解答例)へのリンクと、解答例から転記した正答で演習できる。解説・分野メモ・学習ノートは自作。

## 試験の構成(高度試験共通)

| 時限 | 内容 | 時間 | 出題形式 | 合格基準 |
|---|---|---|---|---|
| 午前I | 高度共通(全区分共通) | 50分 | 多肢選択 30問 | 60点以上(正答率60%) |
| 午前II | 区分別の専門知識 | 40分 | 多肢選択 25問 | 60点以上 |
| 午後I | 区分別、事例を読んで記述 | 90分 | 記述式 3問中2問選択 | 60点以上 |
| 午後II | 区分別、論述 | 120分 | 論述 2問中1問選択 | ランクA |

午前I・午前II・午後Iのいずれかが基準未満だと、それ以降の採点は行われない(足切り)。午前Iは他の高度区分の受験でも共通で、一定条件で2年間免除される制度がある(詳細はIPA公式で確認すること)。

## このサイトの収録範囲

| 区分 | 内容 | 状況 |
|---|---|---|
| [午前I(共通)](am1/) | 過去問演習(令和4〜7年度 秋期) | 正答のみ。分野・解説は未 |
| [PM 午前II](pm/am2/) | 過去問演習(令和4〜7年度 秋期) | 正答のみ。分野・解説は未 |
| [PM 午後I](pm/pm1/) | 分野別の学習ノート | テーマ別ノートを作成 |
