# プロジェクトマネージャ試験(PM)

システム開発プロジェクト全体の計画・実行・統制を担う人材向け。午前II、午後I(記述)、午後II(論述)で構成される。

| 区分 | ページ |
|---|---|
| 午前II 過去問演習 | [午前II(PM)](am2/) |
| 午後I 学習ノート | [午後I 学習ノート](pm1/) |

## 午後Iの出題の特徴

- 3問から2問を選択、各50点満点、90分(1問あたり約40分が目安)。
- プロジェクトの場面(開発・調達・体制変更など)を読み、問題点の特定・原因・対策・判断理由を記述する。
- 解答は「本文の根拠 → 何をすべきか」の形で、設問の字数制限内に収める。
