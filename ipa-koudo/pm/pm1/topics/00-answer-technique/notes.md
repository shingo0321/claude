# 00. 解答の型と時間配分

## 時間配分(90分・2問選択)

| 手順 | 目安 |
|---|---|
| 3問を流し読みして2問を選ぶ | 5分 |
| 1問目(読む→設問→本文に根拠を印→記述) | 40分 |
| 2問目 | 40分 |
| 見直し(字数・主語・設問の聞き方との対応) | 5分 |

得意テーマ(調達・リスクなど)より、**本文の状況が追いやすい問題**を選ぶ。

## 読み方

1. 設問を先に読み、何を聞かれているか(原因/対策/理由/影響)を把握する。
2. 本文の「事実」「担当者の発言」「問題の兆候」に線を引く。PM試験は、**解答の根拠が本文中に必ずある**。
3. 設問と本文の該当箇所を対応付けてから書く。

## 解答の型

| 設問の聞き方 | 型 |
|---|---|
| 問題点・原因 | 〜が〜していなかったから / 〜の確認が不足していたから |
| 対策・実施すべきこと | 〜を〜することで〜を防ぐ(具体的な行為+目的) |
| 理由 | 〜なので〜と判断した(本文の事実を1つ引く) |
| 影響 | 〜が遅延する / 〜の品質が低下する(対象+結果) |

## 注意点

- 字数制限の8〜10割を使う。短すぎると要素不足、超過は無効。
- 主語と対象を明確にする(「誰が」「何を」)。
- 一般論より本文の語句を使う。ただし**本文の丸写しはしない**(設問が聞く観点に合わせて言い換える)。
- 迷ったら「プロジェクトの目的(QCD)に対し、どのリスクを減らす行為か」で書く。
